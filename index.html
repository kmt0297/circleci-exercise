Deployed by CircleCI

A tested Docker image, shipped automatically

This page is running from a Docker image that CircleCI built, tested against a real Postgres database, and deployed to Render after a merge to main.

How it got here

1
Build Every push builds the app into a Docker image and pushes it to Docker Hub, tagged with the commit ID.
→
2
Test pytest runs inside that image with a Postgres sidecar. CircleCI collects the JUnit results.
→
3
Deploy Only on main, and only if tests pass. Render runs the exact image that was tested.

What it's made of

AppPython, saving and counting users in Postgres
Testspytest with JUnit XML results
DatabasePostgres 16, running as a sidecar container
PipelineCircleCI: build → test → deploy
Image registryDocker Hub, tagged by commit
HostingRender, running the pre-built image
